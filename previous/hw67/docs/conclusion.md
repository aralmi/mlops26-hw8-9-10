## Ограничения и следующий шаг

Обучение учит свободным ответам pandas, а golden требует короткую JSON-метку. Такое различие разрешено протоколом, но снижение token loss само по себе не доказывает улучшение выбора вариантов, формата и отказов. Следующий шаг — добавить отдельные train-примеры формата/отказа и сравнить кандидатов при одинаковом увеличенном бюджете. Протокол этой оценки не менять задним числом; для итогового независимого вывода подготовить новый неиспользованный набор.

BLEU/ROUGE оценивают совпадение слов, BERTScore — близость представлений. Почти одинаковые JSON с разными метками могут иметь высокое сходство, хотя один ответ неверен. Здесь точный scorer полезнее. Модель-судья могла бы разбирать свободные объяснения и корректность кода, но подвержена предпочтению позиции A/B, длины и стиля ответа и сама ошибается. Понадобились бы слепое сравнение, перестановка A/B, рубрика и проверка спорных вердиктов человеком. Judge и платный API не использовались.
