# Данные и атрибуция

Train/val взяты побайтово из собственного
[ДЗ4](https://github.com/aralmi/mlops26-hw4/tree/026e8c94671f30ae9fb2ca3cccbc3018f41d3712).
Происхождение и SHA256 — в `docs/data-lineage.json`. Это производные вопросы
и ответы Stack Overflow из ДЗ3; исходная атрибуция авторов и ссылки сохранены
в `data/eval/train-attribution.jsonl` и приложении `submission/evaluation-data.zip`.
Условия исходного набора — CC BY-SA 4.0, как в DATA_LICENSE.md ДЗ4.
Индекс train содержит только id, group_id и тексты вопросов; данные не
токенизируются заново и не сокращаются при переносе. Бюджет обучения задаёт
только число используемых примеров/обновлений, не меняя входные файлы.

50 golden-примеров — новые небольшие фрагменты кода с самостоятельно
заданными значениями и дистракторами, а не скопированные вопросы Stack Overflow.
Проверка значений выполнена на pandas 2.3.3. Поле source ссылается на
официальную документацию операций; оно не означает, что формулировка
вопроса дословно взята из документации. Скрипт и протокол позволяют
воспроизвести разметку до запуска модели.

Веса Qwen и LoRA-пакеты не включены в Git или приложение с данными оценки.
