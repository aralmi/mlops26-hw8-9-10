## Настоящая модель — отдельный этап

```bash
make install-model
make prepare-real
make smoke
```

`prepare-real` читает существующий локальный HF snapshot, пересчитывает файлы
и импортирует **ранее закреплённую baseline**. Веса не скачиваются неявно.
Baseline не выдаётся за нового кандидата с PASS: в `baseline-import.json`
записано `quality_passed: false` и происхождение принятой опорной версии.
`smoke` запускает реальный API на свободном порту, получает ответ, сравнивает
его с прежним ответом eval и останавливает свой процесс.

Кандидат из ДЗ 6–7 остаётся отклонённым. Для проверки его выпуска нужен
существующий MLflow ДЗ 6–7, который следует включить отдельно, когда разрешён запуск:

```bash
make fetch-candidate
make prepare-candidate
make release
```

`fetch-candidate` читает готовый run; обучения нет. `release` повторно считает
прежние метрики из сырых ответов, вызывает прежний quality gate и сохраняет
`release-report.json`. Для нашего кандидата ожидается отказ с ненулевым кодом
и неизменным `accepted.json`. Это ожидаемый результат, а не основание ослаблять gate.

## API и измерения

После проверки окружения и manifest в одном терминале:

```bash
make serve
```

В другом:

```bash
curl http://127.0.0.1:8091/health
curl http://127.0.0.1:8091/ready
make replay
make benchmark
```

Сервис работает на `127.0.0.1:8091`; схема — `/docs`. Остановка — Ctrl+C
в терминале сервера. Один процесс, без `--reload`. Лимит настоящего API — ровно
32 новых токена, как в оценке; менять generation-настройки запросом нельзя.
`replay` проверит все 50+3 прежних ответа baseline, `benchmark` сохранит 8+8
настоящих запросов. Для CPU разрешены 4+4: `python scripts/benchmark.py --n 4`
из подготовленного окружения. Новый замер требует нового выходного каталога.

Путь в локальном manifest зависит от машины. На другой машине базу получают
из публичного `Qwen/Qwen3-0.6B` по revision
`c1899de289a04d12100db370d81485cdf75e47ca`, затем создают свои manifest и
проверяют тот же inventory `config/base-files.json`. Адаптер доступен в
локальном MLflow: training run `1efd3e7eeda54bfc9ee161cf28065807`,
artifact `model/artifacts/adapter`. Для проверки отказа из сохранённых
ответов доступны полный eval, исходные данные и код в репозитории;
повторить загрузку самого адаптера без его экспорта нельзя.

Веса, `.venv`, Prefect-кеш, рабочие каталоги, секреты и видео исключены из Git.
Удалённый CI, защита merge, новая оценка и результаты этой работы пока не заявляются.
